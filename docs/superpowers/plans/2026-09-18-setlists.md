# Setlists Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add setlists to Arc — a Laravel API for CRUD, add/remove/reorder songs, and per-setlist key selection, plus the Flutter screens to manage them and jump into a song already transposed to the setlist's chosen key — matching `docs/superpowers/specs/2026-09-17-setlists-design.md`.

**Architecture:** Backend: two new tables (`setlists`, `setlist_songs`), a `Setlist` model with an ordered `songs` relation through the pivot, and REST endpoints including a dedicated reorder endpoint that rewrites `position` for the whole list atomically. Frontend: mirrors the existing Songs feature's file structure (model/repository/provider/screens) under `lib/features/setlists/`, reusing `SongRepository`'s search for the "add song" picker and extending `SongDetailScreen` with an optional initial-key parameter.

**Tech Stack:** Laravel 13 (PHP 8.3, MySQL), PHPUnit feature tests; Flutter 3.44 (Dart 3.12), Riverpod 3.x (`Notifier`/`AsyncNotifier`), `ReorderableListView`.

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\StoreSetlistRequest;
use App\Http\Requests\UpdateSetlistRequest;
use App\Models\Setlist;
use Illuminate\Http\Request;

class SetlistController extends Controller
{
    public function index(Request $request)
    {
        $setlists = Setlist::query()->orderBy('service_date')->get();

        return response()->json(['data' => $setlists]);
    }

    public function store(StoreSetlistRequest $request)
    {
        $setlist = Setlist::create([
            ...$request->validated(),
            'created_by' => $request->user()->id,
        ]);

        return response()->json(['data' => $setlist], 201);
    }

    public function show(Setlist $setlist)
    {
        $setlist->load('setlistSongs.song');

        return response()->json(['data' => $setlist]);
    }

    public function update(UpdateSetlistRequest $request, Setlist $setlist)
    {
        $setlist->update($request->validated());

        return response()->json(['data' => $setlist]);
    }

    public function destroy(Setlist $setlist)
    {
        $setlist->delete();

        return response()->noContent();
    }
}
```

Create `arc-backend/app/Http/Requests/ReorderSetlistSongsRequest.php`. This one needs access to the route's `{setlist}` to validate the ID set matches — use a closure-based rule:

```php
<?php

namespace App\Http\Requests;

use App\Models\SetlistSong;
use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Validation\Validator;

class ReorderSetlistSongsRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return [
            'setlist_song_ids' => ['required', 'array'],
            'setlist_song_ids.*' => ['integer'],
        ];
    }

    public function withValidator(Validator $validator): void
    {
        $validator->after(function (Validator $validator) {
            $setlist = $this->route('setlist');
            $given = collect($this->input('setlist_song_ids', []))->sort()->values();
            $actual = SetlistSong::where('setlist_id', $setlist->id)
                ->pluck('id')
                ->sort()
                ->values();

            if (! $given->equals($actual)) {
                $validator->errors()->add(
```

```php
namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\ReorderSetlistSongsRequest;
use App\Http\Requests\StoreSetlistSongRequest;
use App\Http\Requests\UpdateSetlistSongRequest;
use App\Models\Setlist;
use App\Models\SetlistSong;
use App\Models\Song;

class SetlistSongController extends Controller
{
    public function store(StoreSetlistSongRequest $request, Setlist $setlist)
    {
        $song = Song::findOrFail($request->validated('song_id'));
        $nextPosition = $setlist->setlistSongs()->count();

        $setlistSong = $setlist->setlistSongs()->create([
            'song_id' => $song->id,
            'position' => $nextPosition,
            'key' => $request->validated('key') ?? $song->original_key,
        ]);

        return response()->json(['data' => $setlistSong], 201);
    }

    public function update(UpdateSetlistSongRequest $request, Setlist $setlist, SetlistSong $setlistSong)
    {
        $setlistSong->update(['key' => $request->validated('key')]);

        return response()->json(['data' => $setlistSong]);
    }

    public function destroy(Setlist $setlist, SetlistSong $setlistSong)
    {
        $setlistSong->delete();

        return response()->noContent();
    }

    public function reorder(ReorderSetlistSongsRequest $request, Setlist $setlist)
    {
        foreach ($request->validated('setlist_song_ids') as $position => $setlistSongId) {
            SetlistSong::where('id', $setlistSongId)->update(['position' => $position]);
        }

        return response()->json(['data' => $setlist->setlistSongs()->get()]);
    }
}
```

```dart
      serviceDate: _serviceDate,
```

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../songs/song.dart';
import '../songs/song_detail_screen.dart';
import 'add_song_to_setlist_screen.dart';

import 'setlist_repository.dart';

class SetlistDetailScreen extends ConsumerStatefulWidget {
  const SetlistDetailScreen({super.key, required this.setlistId});

  final int setlistId;

  @override
  ConsumerState<SetlistDetailScreen> createState() => _SetlistDetailScreenState();
}

class _SetlistDetailScreenState extends ConsumerState<SetlistDetailScreen> {
  Setlist? _setlist;
  bool _isLoading = true;
  String? _errorMessage;

  @override
  void initState() {
    super.initState();
    _load();
  }

  Future<void> _load() async {
    setState(() {
      _isLoading = true;
      _errorMessage = null;
    });
    try {
      final setlist = await ref.read(setlistRepositoryProvider).getOne(widget.setlistId);
      if (mounted) setState(() => _setlist = setlist);
    } catch (_) {
      if (mounted) setState(() => _errorMessage = 'No se pudo cargar el setlist.');
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

  Future<void> _onReorder(int oldIndex, int newIndex) async {
    final setlist = _setlist;
    if (setlist == null) return;

    final songs = List<SetlistSong>.from(setlist.songs);
    if (newIndex > oldIndex) newIndex -= 1;
    final moved = songs.removeAt(oldIndex);
    songs.insert(newIndex, moved);

    // Optimistic: reorder locally immediately, persist in background.
    setState(() => _setlist = Setlist(
          id: setlist.id,
          serviceDate: setlist.serviceDate,
          name: setlist.name,
          songs: songs,
        ));

    try {
      await ref.read(setlistRepositoryProvider).reorder(
            setlistId: setlist.id,
            setlistSongIds: songs.map((s) => s.id).toList(),
          );
    } catch (_) {
      // Revert to the last known-good server state.
      if (mounted) {
        setState(() => _errorMessage = 'No se pudo guardar el nuevo orden.');
      }
      await _load();
    }
  }

  Future<void> _removeSong(SetlistSong setlistSong) async {
    final setlist = _setlist;
    if (setlist == null) return;
    try {
      await ref.read(setlistRepositoryProvider).removeSong(
            setlistId: setlist.id,
            setlistSongId: setlistSong.id,
          );
      await _load();
    } catch (_) {
      if (mounted) setState(() => _errorMessage = 'No se pudo quitar la canción.');
    }
  }

  Future<void> _openAddSong() async {
    final setlist = _setlist;
    if (setlist == null) return;
    final added = await Navigator.of(context).push<bool>(
      MaterialPageRoute(builder: (_) => AddSongToSetlistScreen(setlistId: setlist.id)),
    );
    if (added == true) await _load();
  }

  /// A setlist entry only carries title/artist/key for display in this
  /// list — not the full song (content, tempo, attachments). Navigate to a
  /// loader that fetches the real song before handing off to
  /// SongDetailScreen, passing this setlist's chosen key as the initial key.
  void _openSong(SetlistSong setlistSong) {
    Navigator.of(context).push(
      MaterialPageRoute(
        builder: (_) => _SongFromSetlistLoader(
          songId: setlistSong.songId,
          initialKey: setlistSong.key,
        ),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    final setlist = _setlist;
    final dateLabel = setlist == null
        ? ''
        : '${setlist.serviceDate.day.toString().padLeft(2, '0')}/${setlist.serviceDate.month.toString().padLeft(2, '0')}/${setlist.serviceDate.year}';

    return Scaffold(
      appBar: AppBar(title: Text(setlist?.name?.isNotEmpty == true ? setlist!.name! : dateLabel)),
      body: _isLoading
          ? const Center(child: CircularProgressIndicator())
          : setlist == null
              ? Center(child: Text(_errorMessage ?? 'Setlist no encontrado.'))
              : Column(
                  children: [
                    if (_errorMessage != null)
                      Padding(
                        padding: const EdgeInsets.all(12),
                        child: Text(
                          _errorMessage!,
                          style: TextStyle(color: Theme.of(context).colorScheme.error),
                        ),
                      ),
                    Expanded(
                      child: setlist.songs.isEmpty
                          ? const Center(child: Text('Todavía no hay canciones en este setlist.'))
                          : ReorderableListView.builder(
                              itemCount: setlist.songs.length,
                              onReorder: _onReorder,
                              itemBuilder: (context, index) {
                                final setlistSong = setlist.songs[index];
                                return ListTile(
                                  key: ValueKey(setlistSong.id),
                                  title: Text(setlistSong.songTitle),
                                  subtitle: Text(setlistSong.songArtist ?? ''),
                                  trailing: Row(
                                    mainAxisSize: MainAxisSize.min,
                                    children: [
                                      Text(setlistSong.key),
                                      IconButton(
                                        icon: const Icon(Icons.close),
                                        onPressed: () => _removeSong(setlistSong),
                                      ),
                                    ],
                                  ),
                                  onTap: () => _openSong(setlistSong),
                                );
                              },
                            ),
                    ),
                  ],
                ),
      floatingActionButton: setlist == null
          ? null
          : FloatingActionButton(
              onPressed: _openAddSong,
              child: const Icon(Icons.add),
            ),
    );
  }
}

/// Fetches the full [Song] (content, tempo, attachments) for [songId] before
/// handing off to [SongDetailScreen], since a setlist entry only carries
/// enough data (title/artist/key) for display in the setlist list itself.
class _SongFromSetlistLoader extends ConsumerWidget {
  const _SongFromSetlistLoader({required this.songId, required this.initialKey});

  final int songId;
  final String initialKey;

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    return FutureBuilder<Song>(
      future: ref.read(songRepositoryProvider).getOne(songId),
      builder: (context, snapshot) {
        if (snapshot.connectionState != ConnectionState.done) {
          return const Scaffold(body: Center(child: CircularProgressIndicator()));
        }
        if (snapshot.hasError || !snapshot.hasData) {
          return Scaffold(
            appBar: AppBar(title: const Text('Error')),
            body: const Center(child: Text('No se pudo cargar la canción.')),
          );
        }
        return SongDetailScreen(song: snapshot.data!, initialKey: initialKey);
      },
    );
  }
}
```
