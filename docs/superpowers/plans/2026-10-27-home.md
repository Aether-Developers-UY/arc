# Inicio (Home) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar una pantalla de Inicio, primera pestaña de la app, con hasta 3 setlists fijados por dispositivo, accesos a Biblioteca y Setlists y un espacio "Próximamente".

**Architecture:** Todo en `arc_app` (sin backend). Un `AsyncNotifier<List<int>>` guarda los ids fijados en `SharedPreferences`; cada bloque carga su setlist con un `FutureProvider.autoDispose.family` sobre `SetlistRepository.getOne`. `HomeScreen` se agrega como índice 0 del `IndexedStack` de `AppShell`.

**Tech Stack:** Flutter 3.44 / Dart 3.12, Riverpod 3 (`AsyncNotifier`, sin `StateNotifier`), `shared_preferences`, Dio (`DioException`), tema Arca (`ArcaCard`, `PageHeader`, `ContentFrame`, `context.arca`).

**Spec:** `docs/superpowers/specs/2026-10-27-home-design.md`

## Global Constraints

- Máximo de fijados: **3** (`kMaxPinnedSetlists = 3`), en orden de fijado.
- Clave de `SharedPreferences`: `pinned_setlist_ids` (lista de strings). Una sola clave por dispositivo, sin separar por usuario.
- Solo se desfija solo ante `DioException` con `response?.statusCode == 404`; cualquier otro error muestra "No se pudo cargar" con "Reintentar" y no desfija.
- No se modifica el backend ni `SetlistRepository`.
- Escritorio = `isWide(context)` (>= 900 px): 3 bloques en una fila (`Expanded`). Celular: misma fila deslizable horizontalmente, cada bloque ~70% del ancho.
- Textos de UI en español rioplatense (voseo). Textos exactos: `Inicio`, `Fijados`, `+ Fijar setlist`, `Todavía no elegiste un culto`, `Elegir setlist`, `Biblioteca de canciones`, `Todos los setlists`, `Próximamente`, `Quitar de fijados`, `No se pudo cargar`, `Reintentar`, `N canciones`.
- Tests con `ArcaTheme.useGoogleFonts = false` en `setUp`. Cada bloque muestra hasta 3 canciones (`título · tono`; solo título si no hay tono) y una línea `N canciones`.
- Windows: correr `flutter` desde PowerShell en `C:\wamp64\www\arc\arc_app`. No editar archivos con acentos usando `Get-Content`/`Set-Content` (usar Edit/Write).
- Nada de dependencias nuevas.

## Review Focus

- Prefs corruptas (valores no numéricos en `pinned_setlist_ids`): se ignoran sin crashear — Task 1.
- Prefs con más de 3 ids o ids repetidos: se truncan a 3 y se deduplican — Task 1.
- Setlist sin nombre (`name == null`) o sin canciones (0 canciones): el bloque se renderiza igual — Task 2.
- Error de red/500 en un bloque no desfija y no rompe los otros bloques; 404 sí desfija — Task 2.
- Todos los setlists ya fijados / ninguno creado: la hoja "Fijar setlist" no queda vacía sin explicación — Task 3.
- Ancho de celular (360 px) con 3 fijados: sin overflow — Task 3.
